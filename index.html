Before importing
  • Use the template headings without renaming them.
  • Include a unique Match ID for every row; existing IDs update matching records.
  • Use registered, active Player IDs. Unknown IDs are rejected and never created automatically.
  • The whole batch is validated before it is saved. Correct any errors and upload again.
